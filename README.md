# SuperNote Classic — Android starter project

This is an original Android starter project inspired by classic notebook apps. It is **not** the original ASUS SuperNote app and does not include ASUS proprietary source code, logos, or assets.

## Current prototype
- Finger drawing / handwriting on a white page
- Black, blue and red pen selection
- Simple white-stroke eraser
- Clear page
- Save current page as a PNG inside the app's private storage

## Build
1. Download and install Android Studio on a Windows, Mac, or Linux computer.
2. Open this folder in Android Studio.
3. Allow Gradle sync to finish.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Install the resulting APK on your Android phone for testing.
